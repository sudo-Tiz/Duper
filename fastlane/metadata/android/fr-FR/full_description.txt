Duper vous permet de contrôler votre téléphone Android à distance par SMS. L'application n'a ni compte, ni serveur, ni SDK de suivi, ni permission Internet.

Envoyez "duper ring" pour faire sonner votre téléphone au volume maximum avec le flash qui clignote, même en mode silencieux. Pratique quand vous avez perdu votre téléphone à proximité.

Envoyez "duper locate" pour recevoir des coordonnées GPS par SMS à intervalles réguliers. Utile en cas d'urgence ou quand vous prêtez votre téléphone à quelqu'un.

Fonctionnalités :
• Sonnerie avec flash, contourne le mode silencieux
• Suivi GPS par SMS
• Les deux modes s'arrêtent quand le téléphone est déverrouillé
• Préfixe de commande, mot de passe Sonnerie facultatif, secret Localisation, durée et intervalle configurables
• Sonnerie personnalisée
• Fonctionne entièrement hors ligne via SMS
• Aucun compte, aucun cloud, aucun tracking

La permission Appareil photo est utilisée uniquement pour contrôler la torche pendant une alerte. Duper ne prend ni photo ni vidéo.

La localisation utilise les permissions de localisation, y compris en arrière-plan lorsque l'application est fermée. La permission facultative WRITE_SECURE_SETTINGS, accordable uniquement via ADB, permet à Duper d'essayer d'activer les services de localisation Android lorsqu'ils sont désactivés. Elle n'est pas nécessaire si la localisation est déjà activée.

Les modes Sonnerie et Localisation sont désactivés par défaut. La Sonnerie peut utiliser un mot de passe facultatif ; la Localisation nécessite son propre secret. L'application demande seulement les permissions nécessaires lors de l'activation de chaque mode.

Pour préserver la confidentialité, les commandes distantes fonctionnent seulement lorsque le téléphone est verrouillé et s'arrêtent lors de son déverrouillage.

Remarque : sur Android 13+, il peut être nécessaire d'autoriser les paramètres restreints dans les réglages de l'application avant d'accorder les permissions.
